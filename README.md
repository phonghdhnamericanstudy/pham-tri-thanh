# Phạm Trí Thành

Published portfolio website for https://www.tthanhpham.com/.

## Deployment

Vercel serves the static website in `dist/`. The production branch is `main`; pushing updates to this repository deploys the site automatically.

Edit page content in `dist/**/index.html`, shared styling in `dist/assets/site.css`, and media in `dist/assets/`. Original ASO engineering PDFs are in `dist/assets/documents/`. `vercel.json` configures the static output.
